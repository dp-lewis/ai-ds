# Tokens

Every token is defined in `src/styles/tokens.css`. The samples below read the
custom properties directly, so this page always reflects the real values — and
it re-renders when you flip the theme toolbar.

## Colour

Names are semantic rather than literal: a component asks for `surface` or
`brand`, never `grey-100`. That's what lets the palette change without editing
component styles, and what makes the dark theme a pure token override.

{['--ds-color-bg', '--ds-color-surface', '--ds-color-fg', '--ds-color-fg-muted', '--ds-color-border', '--ds-color-brand', '--ds-color-brand-hover', '--ds-color-brand-fg', '--ds-color-danger', '--ds-color-focus-ring'].map((token) => (

<Row key={token}>
  <Swatch token={token} />
  <Name>{token}</Name>
</Row>
))}

## Space

A 4px base. The scale is deliberately short — an open-ended one invites
one-off values.

{[1, 2, 3, 4, 5, 6, 7, 8].map((step) => (

<Row key={step}>
  <Name>{`--ds-space-${step}`}</Name>
  <Bar token={`--ds-space-${step}`} />
</Row>
))}

## Motion

`--ds-duration-fast` (120ms) is the only duration token. It collapses to `0ms`
under `prefers-reduced-motion`, in `tokens.css`, so individual components don't
have to handle that themselves.
