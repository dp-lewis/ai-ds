# Tokens

Base values are defined in `src/styles/tokens.css`; each brand overrides what it
needs in `src/styles/themes/`. The samples below read the custom properties
directly rather than restating them, so **this page always shows the values for
whichever brand and mode the toolbar has selected** — switch brand and watch it
change.

A brand may override any token, including spacing. Only the colour set is
mandatory; `npm run validate:tokens` checks all four brands define it for both
modes.

## Colour

Names are semantic rather than literal: a component asks for `surface` or
`brand`, never `grey-100`. That's what let four palettes drop in without editing
a single component stylesheet.

There are two border roles. `border` is decorative — card edges, dividers, rules
— and may be a faint hairline. `border-strong` is the boundary that identifies an
interactive control, and clears 3:1 against the page in every brand so the
secondary button stays perceivable even where the brand favours delicate rules.

</Row>
))}

## Space

A 4px base. The scale is deliberately short — an open-ended one invites
one-off values.

Brands scale this to set their density: broadsheet runs at 1.25×, financial at
0.9×, tabloid at 0.75×, and wireframe inherits the base scale unchanged.

{[1, 2, 3, 4, 5, 6, 7, 8].map((step) => (

<Row key={step}>
  <Name>{`--ds-space-${step}`}</Name>
  <Bar token={`--ds-space-${step}`} />
</Row>
))}

## Type

### Families

Named by **role**, not classification. A component asks for `heading` or `body`
and the brand decides the typeface — which is why broadsheet can be serif
throughout while financial pairs a serif headline with a sans body.

{['heading', 'body', 'mono'].map((role) => (

<Row key={role}>
  <Name>{`--ds-font-${role}`}</Name>
  <span style={{ fontFamily: `var(--ds-font-${role})`, fontSize: 'var(--ds-font-size-xl)' }}>
    Chancellor signals shift
  </span>
</Row>
))}

## Motion

`--ds-duration-fast` (120ms) is the only duration token. It collapses to `0ms`
under `prefers-reduced-motion`, in `tokens.css`, so individual components don't
have to handle that themselves.
