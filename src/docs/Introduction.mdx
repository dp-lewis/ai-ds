# ai-ds

A small React design system. Components are styled with CSS Modules that read
every value from a single layer of CSS custom properties, so the palette,
spacing, and type scale are defined in exactly one place.

## Using it

```bash
npm install ai-ds
```

```tsx
import { Button } from 'ai-ds';
import 'ai-ds/styles.css'; // once, at your app's entry point

export function Toolbar() {
  return <Button onClick={save}>Save changes</Button>;
}
```

`styles.css` carries both the token layer and every component's styles.

## Theming

Tokens resolve against `:root`, and the dark set is a `[data-theme="dark"]`
override. Switch themes by setting the attribute — usually on `<html>`:

```ts
document.documentElement.dataset.theme = 'dark';
```

Only colour tokens are theme-scoped. Spacing, radius, and type stay fixed so a
theme change can't reflow the layout. Use the toolbar control above to flip the
whole canvas.

## How it fits together

```
tokens.css          →  --ds-* custom properties, plus the dark override
Button.module.css   →  component styles, referencing only var(--ds-*)
Button.tsx          →  maps props to those class names
src/index.ts        →  the public barrel consumers import from
```

Two rules keep this from drifting:

1. **Component CSS uses `var(--ds-*)` exclusively.** No raw hex values, no
   literal pixel or rem lengths. If a style needs something the token layer
   doesn't have, add a token.
2. **Components never branch on theme.** No `[data-theme]` selectors outside
   `tokens.css`, and no theme value read in JS. Re-pointing a colour token is
   the whole mechanism.

## Adding a component

Copy the `Button` directory's shape — it exists to be the reference:

```
src/components/Card/
  Card.tsx           props → class names, extends the native element's props
  Card.module.css    styles, tokens only
  Card.stories.tsx   tags: ['autodocs'], one story per meaningful state
  index.ts           re-export the component and its prop types
```

Then add the re-export to `src/index.ts`, or it won't ship in the package.
